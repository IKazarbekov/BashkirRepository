# Telegram-бот для изучения башкирского языка

## Назначение
Бот на **aiogram 3** позволяет регистрироваться, входить в аккаунт и хранить сессию.
Сетевая часть (регистрация/логин) вынесена в отдельный модуль `bot/services/auth_api.py`.

## Стек
- Python 3.10+
- aiogram 3 (Bot, Dispatcher, FSM)
- python-dotenv (чтение `.env`)
- aiohttp/httpx — внутри `auth_api` (HTTP-запросы к бэкенду)

## Структура
- `bot/main.py` — точка входа, хендлеры, FSM-состояния, сессии.
- `bot/services/auth_api.py` — `register()` и `login()`: POST-запросы к API,
  возвращают кортеж `(ok, info)`.
- `.env` — содержит `BOT_TOKEN` и адрес API.

## Как работает

### Запуск
1. `load_dotenv()` читает `.env`.
2. Проверяется наличие `BOT_TOKEN`, создаются `Bot` и `Dispatcher`.
3. `dp.start_polling(bot)` запускает цикл обработки сообщений.

### Сессии
`sessions: dict[int, dict]` — в памяти: `telegram_id → {username, token}`.
⚠️ При перезапуске бота сессии теряются (для продакшена — Redis/БД).

### FSM-состояния
- `Reg` (username → password) — регистрация.
- `Login` (username → password) — вход.
FSM позволяет вести многошаговый диалог: бот «помнит», на каком шаге пользователь.

### Команды
| Команда   | Что делает                                         |
|-----------|----------------------------------------------------|
| `/start`  | Приветствие и список команд                        |
| `/register` | Запускает регистрацию (если не залогинен)        |
| `/login`  | Запускает вход (если не залогинен)                 |
| `/me`     | Показывает текущего пользователя                   |
| `/logout` | Удаляет сессию                                     |

### Поток регистрации
1. `/register` → проверка сессии → состояние `Reg.username`.
2. Пользователь вводит имя → сохраняется в `state.update_data`.
3. Ввод пароля → сообщение с паролем удаляется из чата.
4. Проверка длины (≥6) → `auth_api.register(...)`.
5. Ответ: `✅` или `❌ {info}`.

### Поток логина
Аналогично, но при успехе в `sessions` сохраняется токен:
`sessions[user_id] = {"username": ..., "token": info}`.

### Взаимодействие с сервером
`auth_api.register/login` отправляют `POST` на бэкенд с JSON
`{username, password, telegram_id}` и возвращают `(ok, info)`.
`info` при успехе логина — токен доступа.

## Известные замечания
- Лишняя строка `x` после `start()` — синтаксическая ошибка, удалить.
- Тип `sessions` лучше `dict[int, dict[str, str]]`.
- `Bot(token=TOKEN)` вместо повторного `os.getenv`.
- Сессии в памяти — не переживают рестарт.
