# Башҡорт теле — Flutter

## Запуск в Chrome через Android Studio

Сначала **обязательно запустите Python API** из папки `backend_api` (см. `backend_api/README.md`). Затем откройте **именно `flutter_app`** в Android Studio и запустите:

```bash
flutter pub get
flutter run -d chrome --web-port=5050 --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Для сохранения авторизации в браузере между запусками используйте один и тот же порт (в примере `5050`): локальное хранилище Chrome зависит от адреса и порта.

В первый раз открывается экран **Войти / Регистрация**. Зарегистрируйтесь, после чего приложение откроет уроки. Далее логин, XP, пройденные уроки, избранное, имя и выбранный голос сохраняются на сервере в SQLite. При повторном открытии с действующим токеном вход выполняется автоматически.

Если кнопка входа пишет «Не удаётся связаться с сервером», проверьте http://127.0.0.1:8000/health. В Chrome обращение к `localhost` работает, если API запущен **на том же компьютере**.

## Android-эмулятор

Сервер должен работать с флагом `--host 0.0.0.0`. Для эмулятора Android адрес компьютера — `10.0.2.2`:

```bash
flutter run -d emulator-5554 --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

Имя устройства может отличаться. Посмотреть список: `flutter devices`; если эмулятор единственный, достаточно `flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000`. Для **физического Android-телефона** используйте локальный IP компьютера в Wi-Fi, например `http://192.168.1.10:8000`, и разрешите входящие подключения в брандмауэре. Для удалённого сервера используйте HTTPS.

В debug AndroidManifest разрешён HTTP для локального тестирования. В релизной сборке используйте HTTPS.

## Озвучка

В профиле есть блок **Настройки озвучки** — выбор языка и голоса с сохранением в аккаунте. По умолчанию: башкирский, Айгуль. В словаре и заданиях добавлены кнопки с динамиком. Пункт **Послушать голос** озвучивает образец на выбранном языке.

Озвучка работает только после установки необязательных серверных зависимостей:

```bash
cd ../backend_api
pip install -r requirements-tts.txt
```

Затем вернитесь к приложению и перезапустите Python API. Первая озвучка может быть медленной из-за загрузки модели. Изменение языка в настройках изменяет **язык синтеза**, а не язык интерфейса и не переводит уроки.

## Проверка

```bash
flutter analyze
flutter test
flutter run -d chrome --web-port=5050 --dart-define=API_BASE_URL=http://127.0.0.1:8000
```

Шесть прежних уроков, словарь, XP, серия дней, достижения и прежний интерфейс сохранены. Если в старой автономной версии вы уже проходили уроки, их данные остались в локальном хранилище старой версии браузера, и **не переносятся автоматически** между аккаунтами. Если старые данные доступны по тому же веб-адресу и порту, в профиле можно нажать «Перенести старый прогресс» и подтвердить перенос в текущий аккаунт. Новый прогресс сохраняется в SQLite.

## Telegram Mini App

Чтобы открывать веб-приложение через Telegram, разместите `flutter build web --dart-define=API_BASE_URL=https://api.example.com` на HTTPS-сайте. В `telegram_bot/.env` настройте `WEBAPP_URL` и `API_URL`. URL внешнего API должен иметь HTTPS, а серверный `BASHKIR_ALLOWED_ORIGINS` должен включать адрес вашего сайта. Telegram-бот и Flutter используют один сервер аккаунтов, но автоматический вход по Telegram `initData` пока не реализован: в Mini App пользователь входит своим логином и паролем.

## Если компилятор показывает команды терминала в `lib/main.dart`

Это означает, что в файл исходного кода случайно вставили текст из терминала.
`lib/main.dart` должен содержать только код Dart; команды `cd`, `pip`, `source`, `uvicorn` выполняются в окне **Terminal**, а не в редакторе. В этой версии ZIP `lib/main.dart` уже восстановлен.

## Ежедневная практика и восстановление

В четвёртой версии появилась вкладка **Практика** (после «Уроки»). В ней выбирается пара `ba-ru` / `ba-kaz`, на каждый день показывается фрагмент с предложенным переводом; можно подтвердить или написать правильный вариант. За первый сохранённый ответ начисляется 5 XP. Рядом доступны рейтинги, классы и накопленная база переводов.

При регистрации приложение показывает резервный код один раз. В профиле есть создание нового резервного кода; на форме входа появилась ссылка «Забыли пароль?». Если аккаунт был привязан к Telegram, можно запросить код в личные сообщения. Иначе нужен сохранённый резервный код.

Авторизация запоминается через локальное хранилище каждого устройства и профиля браузера (`shared_preferences`). Поставь отметку «Запомнить меня на этом устройстве». Сохраняй для Chrome один адрес **http://localhost:5050**: `127.0.0.1:5050` является другим местом хранения. XP/уроки/переводы находятся на сервере, поэтому между браузерами они синхронизируются только при входе в один аккаунт.
